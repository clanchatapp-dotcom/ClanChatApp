# ClanChat — Native (Android APK) Google OAuth setup

The web/JS side is fully wired in this repo. The APK's **native shell** (the
`android/` project + `AndroidManifest.xml`) is generated by Emergent's mobile
build pipeline and is **not stored in this repo**, so the two native items below
must be applied by that build (or via Emergent Support).

## What IS done in this repo (web/JS)
- `lib/auth-context.jsx`:
  - Detects Capacitor at runtime (`window.Capacitor`).
  - On native, `signInWithOAuth` uses `redirectTo: "clanchat://auth-callback"`
    with `skipBrowserRedirect: true` (web keeps returning to the site origin).
  - Opens Google in a **Chrome Custom Tab** via `window.Capacitor.Plugins.Browser.open()`
    (falls back to system browser).
  - Listens for `App` plugin `appUrlOpen`, parses the `code`, and calls
    `supabase.auth.exchangeCodeForSession(code)` → existing `SIGNED_IN` flow →
    `/complete-profile`.
- `package.json`: declares the plugins so a `npx cap sync` build includes them:
  - `@capacitor/browser`, `@capacitor/app`, `@capacitor/core`.

## What MUST be done in the native build (Emergent mobile pipeline / Support)
1. **AndroidManifest.xml** — register the custom scheme so `clanchat://` re-enters
   the app (add inside the main `<activity>`):
   ```xml
   <intent-filter>
     <action android:name="android.intent.action.VIEW"/>
     <category android:name="android.intent.category.DEFAULT"/>
     <category android:name="android.intent.category.BROWSABLE"/>
     <data android:scheme="clanchat" android:host="auth-callback"/>
   </intent-filter>
   ```
2. **Ensure the plugins are synced into the APK** (`npx cap sync android`) so the
   `Browser` and `App` plugins are present in the native runtime.

## Supabase dashboard (no code)
- **Authentication → URL Configuration → Redirect URLs** must include:
  - `clanchat://auth-callback`
  - `https://handle-profile-setup.emergent.host` (production web origin)

## After changes
- Redeploy the web app (production runs the deployed build).
- Rebuild the APK so it loads the updated JS + native scheme.
